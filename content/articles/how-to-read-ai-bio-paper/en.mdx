## Start with the biological question

Do not begin with the architecture diagram. First write one sentence describing the biological object the researchers want to measure, predict, or intervene on. Then mark the distance between experimental evidence and the computational proxy.

## Inspect the data boundary

Which tissues, species, platforms, and batches produced the samples? Do train and test sets overlap through patients, donors, or homology? These details determine how far the result can travel.

## Read the leaderboard last

Put baselines, ablations, and failure cases in the same table. A model’s value is not only its average score, but also whether it produces hypotheses that can be tested.
